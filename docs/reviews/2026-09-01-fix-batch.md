## 2. 고친 것 — 무거운 순

### 2.1 도커 배포에서 명단 반영이 항상 죽던 것 (D-01)

`.env.example`이 `ROSTER_IMPORT_PREVIEW_SECRET=""`를 넣고 → compose의 `${VAR:-}`가
빈 문자열을 그대로 넘기고 → `??`는 빈 문자열을 통과시키고 → `secret?.trim()` 가드가
falsy로 떨어져 production에서 throw했다. **`docs/deploy.md`대로 설치하면 예외 없이
걸린다.** 빈 문자열을 「주지 않은 것」으로 보게 고쳤고, 같은 모양의 폴백 셋
(`instrumentation.ts` · `playwright.config.ts` 둘)을 함께 정리했다.

그 예외가 화면에도 서버 로그에도 안 남던 이유가 **D-08**이다 — 서버 액션 열 곳이
예상 못 한 오류를 로그도 재던짐도 없이 삼켰다. 이제 알려진 오류 타입이 아닌 것은
서버 콘솔에 남는다(사용자 문구는 그대로).

### 2.2 재적을 보지 않아 퇴학생에게 상벌점이 부여되던 것 (C-01·C-04·D-03)

부여 게이트가 `User.deletedAt`을 봤는데 **그 값을 채우는 코드가 하나도 없다.**
명단 반영은 퇴학·전학 학생을 `status: "INACTIVE"` · `deletedAt: null`로 두므로
게이트를 그대로 통과했다. 「막는다」고 주석에 적힌 것이 아무것도 안 막고 있었다.

**사용자 결정: 재적으로 막는다.** 그 학년도 `Enrollment.status == "ENROLLED"`로 바꿨고,
검사를 **학년도 잠금 뒤 트랜잭션 안으로** 옮겼다 — 밖에서 하면 학년도 전환과 겹칠 때
지난해 재적을 확인하고 올해에 쓴다.

`removedAt`(Date)은 `removed`(boolean)가 됐다. 학적에는 「언제 바뀌었나」가 없고,
그 자리에 싣던 날짜가 늘 null이라 「삭제됨」 배지와 부여 차단 배너는 **어떤 입력으로도
렌더되지 않는 죽은 코드**였다. 화면 다섯 곳이 이제 학적을 그대로 보여준다.

`merit.repo.ts`의 `deletedAt` 자리 열 곳은 기계적으로 바꾸지 않고 각각 판단했다 —
본인 조회·자녀 조회·학생 상세는 일부러 안 걸렀다(거르면 졸업생의 지난 기록에 닿을
길이 사라진다). 각 자리에 근거를 주석으로 남겼다.

### 2.3 확인 모달이 서버 응답 전에 닫히던 것 (R-01)

`ConfirmDialog`가 성공을 **객체 동일성**(`state !== handled`)으로 판정하는데,
`user-forms.tsx` 두 곳만 매 렌더 새 객체 리터럴을 넘기고 그 `ok`가 제출 전부터
true였다. 제출 순간 pending 재렌더 → 새 객체 → 즉시 닫힘. 「비활성화 중…」이 안 보이고,
서버가 거부해도 모달은 이미 닫혀 있으며 다시 열면 적어둔 사유가 지워졌다.
액션 상태에 `ok`를 두어 서버가 실제로 성공했을 때만 닫힌다.

### 2.4 첨부 두 자리 (D-04 · C-07)

게시판의 「첨부파일 허용」을 끈 뒤 글을 고치면 **기존 첨부가 디스크까지 영구 삭제**됐다
(이 모듈에서 되돌릴 수 없는 유일한 삭제다). 그 게시판에서는 detach 자체를 건너뛴다.

고아 정리가 지운 첨부를 부분 소실로 조용히 통과시키던 것도 막았다 — 「전부 사라짐」일
때만 걸리던 검사를 「요청한 수와 다르면」으로 올렸고, 수정 경로에는 검사가 아예 없던
것을 붙였다.

### 2.5 사진의 EXIF (D-11)

**사용자 결정: 게시판을 가리지 않고 모든 사진에서 벗긴다.** 익명 게시판만 벗기면
우회로가 남는다 — 첨부는 글보다 먼저 올라가고 `attachToPost`는 올린 사람과
`postId: null`만 보므로, 실명 게시판에 올려 그 id를 익명 글에 실으면 그만이다.

의존성을 늘리지 않았다. 재인코딩이 아니라 JPEG의 APP1·PNG의 `eXIf` 청크를 도려내는
방식이라 값이 버퍼 한 벌 복사이고, 벗길 것이 없으면 원본 참조가 그대로 돌아온다.
모션 포토가 사진 뒤에 붙이는 동영상 꼬리도 함께 잘린다. 벗기기에 실패하면 업로드를
거절한다 — 조용히 원본을 저장하면 첨부가 「벗겨졌거나 아닐 수도 있는 것」이 되어
검사가 무의미해진다.

### 2.6 붙여넣은 `+82`가 없는 번호가 되던 것 (RL-33)

```
formatPhone("+82 10-1234-5678")  =>  "821-0123-4567"
```

숫자만 뽑는 과정에서 국가번호 `82`가 국번 자리로 올라간다. 가입·최초 관리자 생성·
계정 정보 수정 **세 화면이 실제로 쓰는** 함수다.

**테스트가 이걸 못 잡은 이유가 그 자체로 결함이었다** — 배열 리터럴 안에서
`"+82 ".replace("+82 ", "0")`으로 스스로 치환한 뒤 함수에 넘겨, 국제 표기를 한 번도
태우지 않았다.
