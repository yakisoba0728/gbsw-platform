## 2026-08-17 리디자인 이후 무엇이 달라졌나

`2026-08-16-codebase-audit.md`를 읽을 때 아래를 함께 알아야 한다. 그 문서가 전제한
디자인·컴포넌트 구조가 바뀌었다.

- **디자인 토큰 전면 교체.** `--color-pri`가 `#00876c` → `#3ecf8e`가 되었고 **배경 전용**이다
  (흰 배경 대비 2:1이라 글자로 쓰면 안 읽힌다). 글자용 초록은 `--color-pri-ink`.
- **`text-display` 토큰은 삭제됐다.** 상단바가 모든 화면에 `<h1>`을 그려 쓸 자리가 없었다.
- **`DataTable`이 생겼다.** 좁은 폭에서 카드 목록으로 바뀌는 표. 기존 `TableFrame`은
  그대로 남아 있고, 표로 세울 수 없는 목록은 둘 다 쓰지 않는다.
- **공용 컴포넌트가 늘었다** — `BackLink`·`SecretPanel`·`StatTile`,
  `SectionCard`의 `variant="panel"`·`tone="danger"`, `Button`의 `size="icon"`.
- **기능 변경 하나** — 규정 삭제가 사유를 받아 감사로그에 남긴다 (`merit:rule:delete`의
  `metadata.reason`).

## 다음에 검토할 만한 것

- **감사로그 IP 보존 기간 정책이 없다.** IP도 개인정보다. 얼마나 오래 남길지, 언제 IP만
  지우고 나머지는 남길지를 업무 모듈이 늘기 전에 정해야 한다.
- **인증코드 발송 남용이 감사로그에 안 보인다.** 대상별 5회/시간·IP별 20회/시간 제한이
  막지만, "누가 얼마나 시도했나"를 되짚을 자료는 없다.
- **`/admin/students/import`가 개인정보를 DOM에 담는다.** 오류 리포팅 도구를 붙일 때
  이 화면을 마스킹 대상에 넣어야 한다.
