## 0. 무엇이 바뀌는가 (한 문단)

지금은 **회색 페이지(#f5f6f8) 위에 흰 카드**가 떠 있고, 진한 학교 초록(#00876c)이
글자·버튼·배지에 두루 쓰이며, 제목은 800(extrabold), 모서리는 10~14px다.

바뀐 뒤에는 **흰 페이지 위에 흰 카드**가 1px 헤어라인으로만 구분되고, 에메랄드
(#3ecf8e)는 **채워진 버튼에만** 쓰이며(글자색으로는 절대 안 쓴다), 제목은 500~600,
모서리는 버튼 6px · 카드 12px다. 색이 사라진 자리는 여백과 선이 대신한다.

## 1. 토큰 — 이름은 그대로, 값만 바뀐다

`src/app/globals.css`의 `@theme`을 내가 이미 교체했다. **아래 표는 참고용이며,
에이전트가 globals.css를 수정할 일은 없다.** 화면 코드는 토큰 이름만 쓴다.

### 표면
| 토큰 | 이전 | 이후 | 쓰임 |
|---|---|---|---|
| `bg` | `#f5f6f8` | `#ffffff` | 페이지 바탕 |
| `surface` | `#ffffff` | `#ffffff` | 카드·패널 |
| `soft` | `#fafbfc` | `#fafafa` | 사이드바 · 표 머리글 · hover · 코드 |
| `line` | `#eaecf0` | `#dfdfdf` | 카드·표 테두리 (기본) |
| `line2` | `#f1f2f5` | `#ededed` | 카드 **안쪽** 구분선 · 표 행 구분 |
| `line-strong` | (없음) | `#c7c7c7` | secondary 버튼 테두리 |

> **핵심 변화.** 페이지와 카드가 둘 다 흰색이다. 카드가 보이는 건 오직 `border-line`
> 때문이다. 그러므로 **카드에서 `border`를 빼면 카드가 사라진다.** 지금까지 회색
> 바탕 덕에 테두리 없이도 카드로 읽히던 곳이 있다면 테두리를 붙인다.

### 글자
| 토큰 | 이전 | 이후 | 쓰임 |
|---|---|---|---|
| `ink` | `#1b2030` | `#171717` | 본문·제목 |
| `mut` | `#737b89` | `#707070` | 보조 설명 |
| `mut2` | `#9aa0ab` | `#9a9a9a` | 3차 보조 |

### 브랜드 — **읽어라, 여기서 사고가 난다**
| 토큰 | 값 | 허용되는 쓰임 |
|---|---|---|
| `pri` | `#3ecf8e` | **배경으로만.** `bg-pri` ✅ / `text-pri` ❌ |
| `pri-press` | `#24b47e` | `bg-pri`의 hover·active |
| `pri-soft` | `#e8f7f0` | 아주 옅은 바탕 (현재 메뉴 등) |
| `pri-ink` | `#0d7a56` | **에메랄드를 글자로 써야 할 때만.** 대비 5.3:1 |
| `on-pri` | `#171717` | `bg-pri` 위의 글자색 |

> `#3ecf8e`는 흰 배경에서 대비 **2.0:1** — 본문은 4.5:1이 필요하다. 지금 코드에
> `text-pri`가 **49곳** 있고 전부 안 읽히게 된다.
>
> **`text-pri` 치환 규칙:**
> 1. 링크 → `text-ink underline underline-offset-2 decoration-line-strong hover:decoration-ink`
>    (시안의 `link-on-light`: 잉크색 + 밑줄. 색으로 링크를 알리지 않는다)
> 2. 현재 메뉴·선택된 탭 → `bg-soft font-medium text-ink` (초록 글자 아님)
> 3. 숫자·아이콘 강조 → `text-ink`
> 4. 그래도 초록이어야 하는 자리 → `text-pri-ink`
>
> `bg-pri` 위 글자는 **`text-on-pri`(근검정)** 다. `text-white`가 아니다 — 시안이
> 명시적으로 뒤집은 부분이다.

### 상태색 — 유지하되 채도를 낮춘다
상벌점 표를 눈으로 훑는 사람에게 상점/벌점 구분은 기능이다. 시안의 "액센트를
시스템 색으로 쓰지 말라"는 마케팅 화면 규칙이고, 여기선 시안의 액센트 팔레트를
그대로 가져와 상태색으로 못박는다. **아래 6쌍 외의 색은 쓰지 않는다.**

| 뜻 | 글자 | 바탕 | 테두리 | 대비 |
|---|---|---|---|---|
| 상점 | `blue` `#054cff` | `blue-soft` `#eef3ff` | `blue-line` `#d6e2ff` | 6.0:1 |
| 벌점·오류·위험 | `rose` `#e2005a` | `rose-soft` `#fdeef4` | `rose-line` `#f7cddd` | 4.8:1 |
| 승인·성공 | `green` `#0d7a56` | `green-soft` `#e8f7f0` | `green-line` `#c7e8da` | 5.3:1 |
| 대기·주의 | `amber-ink` `#8a6116` | `amber-soft` `#fdf6e8` | `amber-line` `#ecd9ae` | 5.5:1 |
| 취소·읽음 | `mut` | `mut-soft` | `line` | — |
| 브랜드 | `pri-ink` | `pri-soft` | `pri-line` `#bfe9d6` | 5.3:1 |

`rose-press` `#c00b4f` (위험 버튼 hover) · `green-press` `#0a6144`.

이전 값 중 `amber-ink #b6791b`(3.7:1)와 `green #0e9f6e`(3.4:1)는 **원래 AA 미달**이었다.
바뀐 값으로 해결된다.

### 굵기 — 800/700을 없앤다
| 이전 | 이후 |
|---|---|
| `font-extrabold` (800) | `font-semibold` (600) |
| `font-bold` (700) | `font-medium` (500) |
| `font-semibold` (600) | `font-medium` (500) |

예외 둘: **카드·페이지 제목은 `font-semibold`(600)**, 그 외 전부 `font-medium` 또는
없음(400). 시안은 500 상한이지만 한글은 라틴보다 얇게 읽혀 제목만 600으로 둔다.
`font-bold`·`font-extrabold`는 최종 코드에 **한 곳도 남지 않아야 한다.**

### 여백
8px 배수. `gap-2`(8) `gap-3`(12) `gap-4`(16) `gap-6`(24) `gap-8`(32).
카드 안쪽 `p-5`(20) 유지, 카드 머리글 `px-5 py-4`. `p-[13px]` 같은 임의 여백은
가장 가까운 배수로 올린다.

### 글꼴
`--font-sans`는 **Pretendard 그대로 둔다.** 시안은 Inter를 권하지만 이 앱은 한글이
본문이고 Pretendard가 한글판 Inter다. 라틴·숫자는 Pretendard가 이미 Inter 계열이다.

**`--font-mono` (`font-mono`)를 새로 넣었다.** 아래는 반드시 mono로 그린다 —
시안의 "developer DNA"를 이 앱에서 되살릴 수 있는 유일한 자리다:
학생코드 · 초대코드 · 인증코드 · 임시 비밀번호 · 감사로그의 대상 ID · 날짜시각.

## 3. 문구 (문안) 규칙

**모든 사용자 노출 문구를 다시 쓴다.** 서버 액션의 `MESSAGES` 사전, 폼 라벨,
placeholder, 빈 상태 문구, 버튼 글자, 확인 모달, 페이지 제목·설명 전부.

`MESSAGES` **구조는 그대로 둔다** (서비스는 코드, 액션이 문구로 옮김). 값만 바꾼다.

### 규칙
1. **한 문장.** 두 문장이 필요하면 둘째는 "다음에 할 일"만 적는다.
2. **고칠 수 없는 이유를 설명하지 않는다.**
   ✗ `발생일이 현재 학년도(3월 1일 ~ 이듬해 2월 말) 밖입니다. 지난 학년도의 일은 부여할 수 없습니다.`
   ✓ `현재 학년도 안의 날짜만 고를 수 있습니다.`
3. **완충어 삭제.** "일 수 있습니다", "다시 시도해 주세요", "죄송" 을 기본으로 붙이지
   않는다. 사용자가 실제로 다시 눌러서 될 때만 "다시 시도" 를 쓴다.
   ✗ `기록을 찾을 수 없습니다. 새로고침 후 다시 시도해 주세요.`
   ✓ `기록을 찾을 수 없습니다.`
4. **느낌표·이모지·물결표 금지.**
5. **용어를 하나로 고정한다.** 아래 표를 벗어난 말을 쓰지 않는다.
6. 빈 상태는 사실만. ✗ `아직 등록된 규정이 없습니다. 오른쪽 위에서 추가해 보세요!` ✓ `등록된 규정이 없습니다.`
7. 버튼은 **동사 하나**. `저장` `삭제` `취소` `부여` `내보내기` `초대` — `~하기` 금지.

### 용어 고정표
| 쓴다 | 쓰지 않는다 |
|---|---|
| 상점 / 벌점 | 가점, 감점, 포인트 |
| 부여 | 지급, 등록, 추가 (상벌점에 한해) |
| 규정 | 항목, 사유 코드 |
| 명단 | 로스터, 리스트 |
| 학년도 | 연도, 년도 |
| 계정 | 유저, 사용자 계정 |
| 감사로그 | 로그, 이력 |
| 내보내기 | 다운로드, 익스포트 |

## 4. 주석 — "AI설명" 제거

`src/`에 주석이 **4,202줄**(전체 21,769줄의 19%) 있다. 대부분이 "왜 이렇게 했는지"를
문단으로 설명하는 에세이이고, 이게 이 저장소가 AI가 쓴 것처럼 보이는 가장 큰 이유다.

### 지운다
- 결정 배경·과거 이력을 서술하는 문단
  (`전에는 …였다`, `18곳이 같은 뼈대를 복붙하고 있었다`, `…해서 통일한다`)
- 코드를 읽으면 아는 내용
  (`/** 규정 목록을 가져온다 */` 위의 `listRules()`)
- 대안을 검토하고 기각한 기록 (`X를 쓰지 않는 이유는 …`)
- 시안 대조 주석 (`시안의 Btn 컴포넌트를 …`, `Btn.dc.html의 renderVals()와 1:1`)
- 감정·자평 (`정확히 그걸 빠뜨리고 있었고`, `조용히 실패한다` 류의 서술 문단)
- 파일 상단의 긴 JSDoc 블록 — 한 줄로 줄이거나 없앤다

### **남긴다 (2줄 이내로 줄여서)**
지우면 다음 사람이 같은 함정을 밟는 것들이다. 내용은 유지하되 문장을 자른다.

| 위치 | 남길 사실 |
|---|---|
| `prisma/schema.prisma`, `academic-year.repo.ts` | 부분 유니크 인덱스가 마이그레이션 SQL에만 있다 |
| `globals.css` `dialog:modal` | Tailwind 리셋이 UA margin을 죽인다 |
| `lib/cn.ts` | tailwind-merge가 아니다 — 충돌 해소 안 됨 |
| `ui/table.tsx` | 첫/끝 열 `px-5`, 나머지 `px-3` |
| `ui/note.tsx` | tone="error"면 `role="alert"` 자동 |
| `merit.repo.ts` `isChildOf` | `deletedAt` 필터 없음이 의도 |
| `bootstrap`·`verification` 모듈 | 규약 예외라는 사실 (근거는 CLAUDE.md) |
| `app/api/auth/[...all]/route.ts` | admin 경로 차단 · params를 쓰는 이유 |
| 인쇄 관련 `print:*` | 인쇄에서 높이·넘침을 푸는 이유 |

### 형식
- 한 줄이면 `//`, 두 줄이면 `/** … */`. **세 줄을 넘기지 않는다.**
- 마침표로 끝나는 완결 문장 하나. 접속사로 문단을 잇지 않는다.
- 테스트의 `it("…")` 설명문도 같은 규칙 — `it("권한 거부를 파일 문제로 안내하지
  않는다 — 그래야 다시 누르지 않는다")` → `it("권한 거부는 권한 문구로 안내한다")`

## 5. 테스트

한글 문자열을 단언하는 곳이 **253군데**다. 문구를 바꾸면 깨진다.

- **깨진 단언은 새 문구로 고친다.** 정규식이나 `expect.any(String)`으로 **약화시키지
  않는다** — 그 단언이 문구가 사전에 등록됐는지 확인하는 유일한 장치다.
- 테스트를 **삭제하지 않는다.** 지워야 할 이유가 있으면 보고한다.
- 각 에이전트는 자기 담당 구역의 `tests/` 하위만 만진다.
